# Расписание ВМК — заметки для Claude

Сайт: https://mgucs.github.io/vmk-114-schedule/. Пользователь пишет по-русски и проверяет сайт **на телефоне**:
на Android и на iPhone. Отвечать по-русски, коротко.

## Что важно пользователю

- **Плавность на телефоне важнее эффектов.** Листание дней, вкладок и окон не должно лагать. Живого размытия
  (`backdrop-filter`) на телефоне нет. Прежде чем сказать «не лагает», нужно измерить: Edge, CPU×6, `tools/qa`.
- **Премиально, а не дёшево.** Элементы прямо на фото без подложек (полоса недели, иконки в шапке) — хорошо.
  Тяжёлые стеклянные капсулы — дёшево. Скруглённые квадраты нормальны там, где уже есть (карточки, календарь);
  не избегать их по правилу. Номера групп — кружки.
- **Никаких лишних кнопок и текста.** Переключатель потоков был «лишней кнопкой». Подсказки под настройками
  убраны. Если всё помещается, показывать всё сразу.
- **Только факты из расписания.** Никаких догадок: «лекции в П-5» были неправдой, их убрали. Аудитории
  не показывать там, где они не по сути (например, в выборе группы).
- **Не принимать резких решений и не убирать полезное без спроса.** Если пользователь сказал «верни как было»,
  вернуть точно (по git), а не пересобирать заново.
- **Темы и фон уже утверждены, концепцию не менять:**
  - фон и темы — как после коммита `9c7e8b7` «Тёплая осень»; стили фона из `3749492`;
    `public/brand/msu-*-soft.webp` сделаны `tools/qa/soften.mjs` (blur 7 px, ширина 640);
  - здание МГУ видно чётко: никаких оттенков всего снимка (`--tint`) и сильного размытия — пользователь
    это дважды отклонял («дымка», «токсичные», «опять сильное размытие»);
  - Оникс — серый чёрно-белый снимок (`.wallpaper::after`, `mix-blend-mode:color`);
  - Янтарь («Тёплая осень») — тёплый как Night Shift, `::after` multiply .62;
  - «МГУ классики» нет — это та же «МГУ ночь» (сохранённый выбор переводится в `msu`).
- «Стекло» — первый и основной стиль. Режимов эффектов для выбора нет (всегда `auto`).
  Ползунок «Фон» затемняет фото (`--shade`, по умолчанию 30); пока его тянут, окно настроек прячется.
- Оформление выбирается рулеткой как зум в камере iPhone (`Dial` в `components/personal.tsx`).
  Есть отдельно тёмные, светлые и авто-темы и выбор иконки приложения.
- Кружки пар под днями: лекции — цветом, остальное белым; физра и консультации не красные. Одна пара — один кружок.

## Устройство

Vite 8 + React 19 + TypeScript. Деплой — GitHub Pages: `.github/workflows/pages.yml` каждые 15 минут
скачивает PDF ВМК (`scripts/sync-schedule.mjs`), разбирает его, гоняет `npm test` и собирает сайт.

- `components/snap-pager.tsx` — листание дней на нативном `scroll-snap`. Страницы стоят на весь учебный год
  в фиксированных позициях, рендерится окно near/keep. `onPeek` вызывается во время жеста, `onSettle` — после;
  флаг `gliding` гасит peek при программной прокрутке (кнопка «Сегодня»). Не возвращать JS-анимации свайпа:
  они лагали.
- `components/live-day.tsx` — внешний стор (`useSyncExternalStore`). Через него заголовок дня, полоса недели
  и «К ближайшим» обновляются в тот же кадр, без перерисовки страницы.
- `components/section-tabs.tsx` — нижний dock, только тапы. Линза едет через `transform`; секция меняется
  после кадра анимации.
- `public/parser.mjs` — парсер PDF (pdf.js). При изменении логики поднимать `PARSER_VERSION`
  в `lib/schedule-model.mjs`.
- `lib/guard.mjs` (`guardGroups`) — защита от плохо прочитанного PDF. Если группа подозрительна (пустой
  будний день при занятом потоке или меньше 60% прежних занятий), остаётся её прежнее расписание и появляется
  предупреждение. Если подозрительно больше половины групп — ошибка. Вызывается из `scripts/source-check.mjs`.
- `public/sw.js` — навигация сначала из сети (таймаут 2 с), precache по хешам из `precache.json`
  (`scripts/after-build.mjs`); иконки в precache не входят. Плашки «сайт обновился» нет — пользователь
  просил её убрать.
- Иконки приложения: `public/icons/icon-{night,day,sunset,emblem,vmk}-*.png` и `public/manifest-{key}.webmanifest`.
  Скрипт в `index.html` подменяет manifest по `localStorage['vmk114-icon']`. Генерирует их `tools/qa/icons.mjs`.
- Темы — CSS-переменные в `app/globals.css` (цвета) и `app/glass.css` (стиль «Стекло», фон и фото).
  Список тем — `THEMES` в `components/personal.tsx`; тёмные темы дублируются в массиве в `index.html`.
- Версия сайта (дата из `git log`) — внизу меню «Ещё».

## Проверка перед коммитом

```sh
npm run check     # TypeScript
npm test          # node --test tests/*.test.mjs — только на замороженных данных из tests/fixtures
npm run build
```

Тесты **не должны** читать живые `public/source.json` / `initial.json`: упавший `npm test` в `pages.yml`
блокирует каждый деплой.

Проверка на «телефоне» — `tools/qa/*.mjs`. Они запускаются из корня репозитория после `npm run build`, сами
раздают `dist`, используют `playwright-core` (devDependency) с установленным Edge (`channel:'msedge'`)
и замедляют CPU в 6 раз.

- `shot.mjs out.png [scrollY] [clipTop clipHeight] [style] [theme]` — снимок 390×844.
- `sheet-themes.mjs` — все темы на одном листе. Смотреть его после любой правки тем или фона.
- `swipe.mjs`, `latency.mjs`, `pager-check.mjs`, `today-check.mjs` — свайпы дней: кадры, задержка
  заголовка, согласованность дня и страницы, кнопка «Сегодня».
- `dock-check.mjs`, `dial-check.mjs`, `slider-check.mjs` — dock, рулетки оформления, ползунок «Фон».
- `icons.mjs preview|write` — иконки (фото берутся из `PHOTOS`, по умолчанию `C:/Users/a/Downloads/`).
  `soften.mjs` — размытые копии фото МГУ.

Снимки складывать в `tools/out/` (папка в `.gitignore`) или в scratchpad. Смотреть их глазами
и сравнивать с прошлым видом до того, как говорить «готово».

- Node — системный, `C:\Program Files\nodejs` (`npm.cmd` из Bash).
